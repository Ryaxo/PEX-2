# ⏰ Top-Point - Sistema de Registro de Ponto

---

# 📖 Sobre o Projeto

O **Top-Point** é um sistema web de registro de ponto desenvolvido como projeto acadêmico utilizando **HTML, CSS e JavaScript**.

A aplicação permite cadastrar funcionários, registrar a jornada de trabalho e acompanhar as informações em um dashboard moderno e intuitivo. Os dados são armazenados localmente por meio do **LocalStorage**, dispensando o uso de banco de dados nesta versão.

---

# 🚀 Tecnologias Utilizadas

- **HTML5** – Estrutura da aplicação.
- **CSS3** – Estilização, responsividade e animações.
- **JavaScript (ES6)** – Manipulação do DOM, lógica da aplicação e persistência dos dados.
- **LocalStorage** – Armazenamento local das informações.
- **Font Awesome** – Ícones da interface.
- **Google Fonts (Poppins)** – Tipografia do sistema.

---

# 📋 Funcionalidades

- 👥 Cadastro de funcionários
- ✏️ Edição de funcionários
- 🗑️ Exclusão de funcionários
- 🔍 Pesquisa de funcionários
- ⏰ Registro de Entrada
- ☕ Registro de Intervalo
- ▶️ Registro de Retorno
- 🔴 Registro de Saída
- 📊 Dashboard com indicadores em tempo real
- 📜 Histórico de registros
- 📄 Exportação do histórico em CSV
- 💾 Armazenamento utilizando LocalStorage

---

# ▶️ Como Executar

Após colocar todos os arquivos numa pasta, abra o arquivo index.html em um navegador moderno (Google
Chrome, Microsoft Edge, Mozilla Firefox ou Opera.

Não é necessário instalar dependências ou configurar um servidor.
